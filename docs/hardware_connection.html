📋 接线明细
# Seeed XIAO ESP32S3 Sense 连接 ElectronBot (ESP32-S3) 线色建议 说明
1 GPIO43（UART1 TX，板子印有 TX） → GPIO1（UART2 RX） 紫色 人脸事件单向传输，TX → RX 交叉连接
2 GND（任意 GND 引脚） ⟺ GND（任意 GND 引脚） 黑色 两板必须共地，否则 UART 通信失败
3 3V3 或 5V（可选） → ElectronBot 3.3V 或 5V 输出 橙/红色 可选供电。建议 Seeed 板通过独立 USB-C 供电，避免主控电流不足

📨 UART 通信协议（v2）
参数值说明
波特率115200bps
数据格式8N18 数据位，无校验，1 停止位
消息格式JSON 行协议每条消息以 \n 结尾
消息示例（v2）{"event":"person_greeted","color":"blue","gender":"male","count":1,"confidence":0.92,"person_id":3}Seeed → ElectronBot
color 字段red / orange / yellow / green / cyan / blue / purple / white / black / gray / unknown衣服主色（HSV 统计）
gender 字段male / female / unknown人脸宽高比粗判（非 AI 模型）
person_id 字段0 ~ 7人脸中心 X 区域编号，用于去重判断
去重冷却（Seeed）30000 ms同一 person_id 两次打招呼最小间隔
无人重置（Seeed）12000 ms超过此时间无人出现，重置所有记录
本地防抖（ElectronBot）500 ms主控端额外防连发保护
Seeed TX 引脚GPIO43XIAO ESP32S3 Sense 的 UART1 TX（印丝 TX）
ElectronBot RX 引脚GPIO1ElectronBot ESP32-S3 的空闲 IO，配置为 UART2 RX
⚠️ 注意事项
🔋 供电建议
Seeed XIAO ESP32S3 Sense 工作电流可达 240mA，开启摄像头时更高。
强烈建议通过独立 USB-C 给 Seeed 板供电，避免从 ElectronBot 取电导致主控不稳定。
📍 GPIO1 占用确认
ElectronBot 使用 GPIO1 作为 UART2 RX。请先确认该引脚未被其他外设占用。
如有冲突，可在 face_detect_receiver.cc 中修改 FACE_UART_RX_PIN 为其他空闲 IO。
🔊 个性化问候语（v2）
问候语由代码自动生成，无需录制音频文件。
格式示例："你好蓝色的小哥"、"你好红色的美女"、"你好白色的朋友"。
通过 WakeWordInvoke(greeting) 发送给小智，由小智 TTS 朗读。
如需修改称谓，编辑 face_detect_receiver.cc 的 BuildGreetingText() 函数。
🛠 Seeed 固件编译（v2）
从机固件为独立 ESP-IDF 工程，位于：
main/boards/electron-bot/seeed-sense-face/
新增文件：main/color_gender_analyzer.c/.h（颜色&性别分析）
用 idf.py set-target esp32s3 && idf.py build flash 单独编译烧录到 Seeed 板。
📐 电压兼容性
两块板均为 3.3V IO 电平，直连无需电平转换。
不可直接使用 5V IO（会损坏 ESP32-S3 引脚）。
🧵 接线顺序
建议接线顺序：
1. 先接 GND（共地）
2. 再接 TX → RX 数据线
3. 最后给两块板上电测试
