📶 I²S 音频连接 (ESP32-S3 → Bridge)

  • GPIO17 DOUT → GPIO32 DIN (数据)
  • GPIO18 BCLK → GPIO26 BCLK (位时钟)
  • GPIO8 LRCK → GPIO27 WS (字选择)
  • GND → GND (共地)

* ESP32-S3 为 I²S Master，Bridge 为 Slave

🔗 UART 桥接通信 (Bridge → ESP32-S3)

  • GPIO4 (Bridge UART2 TX) → GPIO2 (ESP32-S3 UART1 RX)
  • GND → GND (共地)

* 波特率: 115200 | 格式: BRIDGE_IP:192.168.x.x

📡 蓝牙音响连接 (Bridge 端)

  • 通过配网页面扫描并连接
  • 支持自动重连上次配对设备
  • A2DP Source 模式发送音频

* 音频自动重采样: 24kHz mono → 44.1kHz stereo

⚠️ 注意事项：
  • 两板共地非常重要，否则 UART 通信可能异常
  • I²S 连接线越短越好，建议不超过 20cm
  • WiFi 连接同一个路由器，确保在同一局域网
  • 首次使用需通过配网页面让 Bridge 发现并连接蓝牙音响
